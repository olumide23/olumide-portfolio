# AI Red-Teaming & Security Evaluation

## Overview
This case study summarizes a practical AI security assessment involving instruction-boundary testing and review of security-relevant model behavior.

## Evaluation approach
- Test model responses against defined scenarios and instructions.
- Observe whether the system follows appropriate instruction boundaries.
- Capture relevant behavior and supporting evidence.
- Describe findings clearly and distinguish observation from interpretation.
- Avoid claiming an issue or exploit unless the evidence supports it.

## Skills demonstrated
Structured testing, instruction-following analysis, careful evidence handling, concise findings, and security-oriented evaluation.

## Evidence note
Assessment content may be governed by confidentiality or project rules. Do not publish private prompts, restricted test cases, credentials, sensitive outputs, or model-reasoning traces. Use only sanitized evidence approved for disclosure.

## Scope
This page is a high-level description. It does not disclose exploit details or claim a vulnerability beyond what approved evidence establishes.
