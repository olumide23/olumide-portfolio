# AI Response Quality Assurance

## Overview
This case study describes a professional workflow for reviewing AI-generated responses against explicit quality criteria. It is based on the user's stated AI evaluation experience and is written as a capability summary rather than a claim about a specific confidential client deliverable.

## Review dimensions
- Factual accuracy and support for claims
- Instruction following
- Clarity and completeness
- Internal consistency
- Reasoning quality
- Appropriate formatting and task completion

## Approach
1. Read the task requirements and evaluation rubric.
2. Review the response against each relevant criterion.
3. Identify errors, unsupported statements, omissions, or instruction mismatches.
4. Record concise, evidence-based findings.
5. Apply the project’s labeling or ranking rules consistently.

## Tools and methods
Structured evaluation rubrics, human-in-the-loop review, comparative response analysis, and written quality feedback.

## Evidence note
Confidential prompts, client data, restricted task content, and private model reasoning are not included. Add screenshots only when disclosure is permitted and the relevant areas have been reviewed and redacted.

## Scope
This page describes work practices and capability areas. It does not claim a specific score, performance uplift, or outcome without approved supporting evidence.
